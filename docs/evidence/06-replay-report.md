## Protocol

1. evaluate the case
2. persist the decision digest
3. persist canonical inputs (contract + evidence set + evaluation time + engine version) with canonical_json
4. reload the snapshot with sufficia.canonical.canonicalize.loads
5. replay in-process and in a separate Python process
6. compare state, reason codes, contract hash, evidence root, fingerprint and canonical decision hash

Replay uses only the original contract snapshot, the original evidence items, the original
evaluation timestamp and the original engine version — never current APIs, prices, block state
or a new LLM call (Document 06 §55).
